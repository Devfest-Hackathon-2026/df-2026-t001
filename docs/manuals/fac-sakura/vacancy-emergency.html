さくら苑 欠員・急変対応マニュアル

この文書は架空の施設「さくら苑」の内部文書として、デモ用に合成したものです。実在の施設・法令・行政の基準を説明するものではありません。文中の時刻・回数・人数はすべてデモ用の仮値です。

1. 欠勤の連絡

体調不良などで勤務に入れなくなった職員は、分かった時点で、職員アプリの「休みの連絡」から送る。夜勤の場合は、勤務開始の4時間前（12:30）までに連絡する（デモ用の仮値）。それより遅いときは、アプリに加えて当日のリーダーへ電話する。

2. 欠員時の連絡順

欠員が出たときは、次の順に連絡する。前の人に10分つながらなければ、次の人へ進む（デモ用の仮値）。

  1. 当日のリーダー（夜間は夜勤リーダー）
  2. 欠員が出たユニットのユニットリーダー
  3. 介護主任
  4. 施設長

連絡を受けた人は、リーダー画面で欠員を登録する。登録すると、ルールに違反しない補充の候補が順に表示される。

3. 打診のルール

  • 打診は、リーダー画面の候補の上から順に、1人ずつ行う。同時に複数の人へ打診しない。
  • 1人への返答の待ち時間は30分とする（デモ用の仮値）。30分たって返答がなければ「期限切れ」にして、次の候補へ打診する。
  • 夜勤明けの職員、連勤5日目に入る職員には打診しない（デモ用の仮値）。
  • 同じ職員への打診は、月に3回までとする（デモ用の仮値）。断られても理由は聞かない。
  • 打診を受けて入った職員には、翌月の勤務希望を優先して反映する。
  • 候補が3人続けて断ったとき、または勤務開始の2時間前を過ぎたときは、ユニット間の応援（他ユニットの夜勤者が2ユニットを見守る）に切り替え、施設長に報告する（デモ用の仮値）。

4. 急変時の対応の流れ

入居者の様子がいつもと違うときは、次の流れで対応する。医療的な判断は看護職員・医師が行い、介護職員は判断しない。

  1. 声をかけ、反応・呼吸・顔色を確認する。
  2. 夜勤リーダーを呼ぶ（他の入居者の見守りを隣のユニットに頼む）。
  3. オンコールの看護職員へ電話し、指示を受ける。
  4. 反応がない・呼吸がおかしいなど、すぐに危険と感じたときは、看護職員の指示を待たずに救急要請してよい。
  5. 家族への連絡は、看護職員または施設長が行う。夜勤者は経過を時刻つきで記録する。

急変の対応で夜勤者が持ち場を離れる場合も、欠員として登録せず、夜勤リーダーが他のユニットの夜勤者に見守りを割り振る。
