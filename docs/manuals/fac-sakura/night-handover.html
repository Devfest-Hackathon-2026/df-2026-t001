さくら苑 夜勤・引き継ぎマニュアル

この文書は架空の施設「さくら苑」の内部文書として、デモ用に合成したものです。実在の施設・法令・行政の基準を説明するものではありません。文中の時刻・回数・人数はすべてデモ用の仮値です。

1. 夜勤の体制

夜勤は16:30から翌朝9:30までの勤務とする（デモ用の仮値）。ひなた・そよかぜ・あかり・つぼみの4ユニットに、各ユニット1名ずつ、合計4名を配置する。

4名のうち1名を「夜勤リーダー」とする。夜勤リーダーは、その夜の連絡の窓口となり、欠員・急変・事故の第一報を受ける。夜勤リーダーは勤務表の作成時に決め、勤務表の備考欄に書く。

夜勤4名のうち、少なくとも1名は喀痰吸引などの医療的ケアの研修を修了した職員とする。この条件は勤務表の「絶対」ルールとして登録している。

2. 夕方の引き継ぎ（16:30〜16:50）

遅番・日勤から夜勤へ、ユニットごとに口頭と記録で引き継ぐ。引き継ぐ項目は次のとおり。

  • 夕食の摂取量と水分量、服薬の状況
  • 日中の体調の変化（発熱・食欲・表情・転倒の有無）
  • 夜間に注意が必要な入居者（離床センサーの対象、吸引が必要な方）
  • 家族からの連絡・来訪の予定
  • 翌日の受診・検査の予定

記録はケア記録アプリの「申し送り」に残す。口頭だけの引き継ぎは行わない。

3. 夜間の巡視

巡視は2時間ごと（22:00・0:00・2:00・4:00）に行う（デモ用の仮値）。離床センサーが鳴ったときは、巡視の時刻に関係なく訪室する。

夜勤者の休憩は、ユニットごとに時間をずらして取る。同じ時間帯に休憩に入るのは最大2名までとし、休憩中の職員のユニットは隣のユニットの夜勤者が見守る。

4. 朝の引き継ぎ（7:00〜7:30）

夜勤から早番へ、ユニットごとに引き継ぐ。夜間の睡眠の状況、排泄、巡視で気づいたこと、夜間に連絡した内容（家族・看護職員・施設長）を伝える。

夜勤リーダーは、夜間に起きた事故・ヒヤリハットを7:30までに記録アプリへ登録し、朝のリーダーに口頭でも伝える。

5. 夜勤明けの扱い

夜勤明けの職員は、その日の勤務に入れない。勤務表では夜勤の翌日を「明け」として扱い、続けて休みを1日とる（デモ用の仮値）。

夜勤は1人あたり月に5回までを目安とする（デモ用の仮値）。
