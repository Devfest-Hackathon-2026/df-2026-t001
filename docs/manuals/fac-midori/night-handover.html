みどりの丘 夜勤・引き継ぎマニュアル

この文書は架空の施設「みどりの丘」の内部文書として、デモ用に合成したものです。実在の施設・法令・行政の基準を説明するものではありません。文中の時刻・回数・人数はすべてデモ用の仮値です。

1. 夜勤の体制

夜勤は16:30から翌朝9:30までとする（デモ用の仮値）。こもれび・せせらぎ・ゆうなぎの3ユニットを、夜勤2名で担当する。1名が1階（こもれび・せせらぎ）、もう1名が2階（ゆうなぎ）と夜間の電話番を受け持つ。

2名のうち経験年数の長い方を夜勤責任者とする。夜勤責任者は、夜間の連絡の窓口になる。

2. 夕方の引き継ぎ（17:00〜17:20）

日勤のリーダーから夜勤責任者へ、全ユニット分をまとめて引き継ぐ（デモ用の仮値）。個別対応が多い施設のため、入居者ごとの「今夜の約束ごと」（就寝前の声かけ、飲み物の好み、トイレの誘導の時刻）を必ず伝える。

  • 服薬・食事・水分の状況
  • 今夜の約束ごと（入居者ごと）
  • 訪問看護・往診の予定と、その連絡先
  • 家族からの依頼

3. 夜間の巡視

巡視は3時間ごと（21:00・0:00・3:00・6:00）とする（デモ用の仮値）。入居者の希望で夜間の訪室を控える方は、引き継ぎの記録に「訪室なし」と書き、センサーで見守る。

休憩は1名ずつ取り、休憩中はもう1名が両方の階を見守る。

4. 朝の引き継ぎ（8:45〜9:15）

夜勤責任者から日勤のリーダーへ引き継ぐ。夜間の出来事、睡眠、排泄、訪問看護への連絡の有無を伝え、記録アプリにも残す。

5. 夜勤の回数

夜勤は1人あたり月4回までを目安とする（デモ用の仮値）。夜勤の翌日は明けとし、勤務に入れない。
