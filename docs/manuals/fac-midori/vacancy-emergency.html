みどりの丘 欠員・急変対応マニュアル

この文書は架空の施設「みどりの丘」の内部文書として、デモ用に合成したものです。実在の施設・法令・行政の基準を説明するものではありません。文中の時刻・回数・人数はすべてデモ用の仮値です。

1. 欠勤の連絡

勤務に入れなくなった職員は、職員アプリの「休みの連絡」から送り、あわせて管理者の携帯へ電話する。夜勤の場合は、勤務開始の6時間前（10:30）までに連絡する（デモ用の仮値）。

2. 欠員時の連絡順

欠員が出たときは、次の順に連絡する。前の人に15分つながらなければ、次の人へ進む（デモ用の仮値）。

  1. 管理者
  2. サービス提供責任者
  3. 当日の日勤リーダー

夜間（21:00以降）は夜勤責任者が管理者へ直接電話する。

3. 打診のルール

  • 打診は、勤務開始の8時間前までに始める（デモ用の仮値）。それより遅くなる場合は、管理者が自分で入るかを先に検討する。
  • 打診は1人ずつ行い、返答の待ち時間は20分とする（デモ用の仮値）。
  • 連勤4日目以上の職員には打診しない（デモ用の仮値）。
  • 夜勤の打診は、同じ職員に月2回までとする（デモ用の仮値）。
  • 直前の依頼・夜勤の依頼は断られやすいため、まず日中の勤務の入れ替え（遅番を夜勤へ回すなど）で埋められないかを確認してから打診する。
  • 2人続けて断られたときは、管理者が補充の方法を決める（デモ用の仮値）。

4. 急変時の対応の流れ

医療的な判断は訪問看護・医師が行い、介護職員は判断しない。

  1. 声をかけ、反応・呼吸・顔色を確認する。
  2. もう1名の夜勤者を呼び、片方が付き添い、片方が連絡する。
  3. 契約している訪問看護の緊急連絡先へ電話し、指示を受ける。
  4. すぐに危険と感じたときは、指示を待たずに救急要請してよい。救急要請したら管理者へ連絡する。
  5. 家族への連絡は管理者が行う。夜勤者は時刻つきで経過を記録する。
